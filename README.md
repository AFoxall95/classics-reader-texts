# Classics Reader texts

Downloadable Latin text packs for the Classics Reader app. `catalog.json` lists
the available texts; each `<id>.json` pack contains the Latin text, an English
translation, word-by-word grammatical analysis, and dictionary entries for the
words in the text.

These files are generated by the Classics Reader pipeline; don't edit them by
hand.
